# DESIGN & UI/UX GUIDELINES

## 1. Visual Theme & Aesthetic
- **Vibe:** Modern agency, sleek dark mode dashboard with energetic competitive game-inspired accents (Deep crimson reds `#991b1b`, `#dc2626`, radiant yellows `#facc15`, and dark slate backgrounds `#090b10`).
- **Typography:** High-contrast, bold, italicized uppercase headers for impact during presentations, paired with clean, readable sans-serif body text.

## 2. Layout Structure
- **Bento Grid & Cards:** Card-based modular layout for projects and log entries to avoid walls of text.
- **Interactive Tabs:** Instant visual feedback when switching squad members. Each member is represented by a 2D SVG avatar with distinct color badges and build types (Light, Medium, Heavy Build).

## 3. Accessibility & Presentation Standards
- High contrast ratios suitable for projector screens in lit classrooms.
- Smooth transitions and hover states (`transition-all`, `duration-300`).
