# PROJECT BRIEF: Web Presentasi & Logbook PKL Kelompok

## 1. Project Overview
A web-based collaborative presentation and daily logbook platform designed for a group of vocational school (SMK) students completing their Praktik Kerja Lapangan (PKL) at government or corporate institutions. 

## 2. Core Objective
Replace traditional printed PKL reports with an interactive, engaging web presentation tailored for final school defense/presentation. While the report is group-unified, individual students (Ahmad, Abimanyu, Rafly, Fero, Alfi) have distinct daily logs and projects based on their unique roles (Web Dev, Network, IT Support, Archive).

## 3. Key User Persona & Audience
- **Primary Users:** The student group members who need to log daily activities easily via a built-in admin dashboard.
- **Audience/Evaluators:** School teachers and industry mentors reviewing the presentation. The design must be striking, highly legible, and professional.

## 4. Key Requirements
- Single-page application (SPA) with responsive design.
- Interactive squad navigation (tabs/cards for each member).
- Dynamic content updating (selecting a member updates their logbook timeline and featured projects).
- Self-contained admin panel for data entry (no complex backend setup required, utilizing local state or cloud sync).
- Clean 2D SVG character illustrations for member representation.
