# TECH STACK SPECIFICATION

## Frontend Framework
- **React.js (Functional Components + Hooks):** For reactive state management and component reusability.
- **Tailwind CSS:** For rapid styling, responsive grid layouts, and custom theme utility classes.

## Icons & Graphics
- **Lucide React:** For crisp, modern UI icons.
- **Custom 2D SVG Illustrations:** Lightweight, vector-based character avatars and dashboard mockups ensuring fast load times and clean presentation without heavy 3D asset dependencies.

## Data Persistence & State
- **React State (`useState`, `useEffect`, `useMemo`):** For real-time UI updates and filtering.
- **Cloud/Local Persistence:** Optional Firebase integration or JSON file export/import for cross-member data sharing.
